# light-ori
오리키우기 게임 (Phaser 프로토타입)

## 실행 방법
```bash
python3 -m http.server 4173
```
브라우저에서 `http://localhost:4173` 접속.

## 중요: 첨부 원본 이미지 사용 방법
요청하신 대로 캐릭터를 변형 없이 그대로 쓰려면, 사용자가 제공한 원본 캐릭터 보드 이미지를 아래 경로로 저장해야 합니다.

- `assets/duck-cast.png`  ← 첨부해주신 원본 이미지 파일 그대로
- `assets/duck-cast.xml`  ← 저장소에 포함(프레임 좌표 정의)

게임은 Phaser atlas로 `duck-cast.png`를 직접 잘라 각 캐릭터를 렌더링합니다.
즉, 이모지/재드로잉이 아닌 원본 시트 비트맵을 그대로 표시합니다.

## 현재 구현 범위
- Phaser 3 기반 캔버스 렌더링
- 성장 단계/맵 해금/호감도/관계/세대 진행
- 맵별 NPC 렌더링(원본 시트 atlas 프레임)
